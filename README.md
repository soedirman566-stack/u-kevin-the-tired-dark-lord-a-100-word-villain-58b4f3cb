# The Tired Dark Lord

Entry for the make.fun competition [The Tired Dark Lord: A 100-Word Villain Monologue](https://make.fun/bounty/u-kevin-the-tired-dark-lord-a-100-word-villain-58b4f3cb).

A 98-word monologue from a dark lord with a real scheme — an eclipse, rising legions, the end of the world — whose exhaustion lives entirely in the deflections: the knees, the back pain that never dies, the apocalypse quietly rescheduled from noon, the thread he keeps losing. He never once says he is tired. He just asks to be woken when it ends.

Run `node main.ts` to write the monologue to `/output/entry.txt`, or `node main.ts <path>` to write it somewhere else.
